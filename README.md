# Yousef Salem — DevOps Engineer Portfolio

Personal portfolio website summarising my DevOps projects, skills and training. It is the web version of my CV, with a link to each project's repository.

**Live site:** https://portfolio-phi-beige-14.vercel.app

## Contents

- **Projects** — each tile opens the project details and links to its repository:
  - [DevSecOps Platform on Amazon EKS](https://github.com/yousefsalemW/DEVSECOPS-PLATFORM-EKS)
  - [Self-Managed High-Availability Kubernetes Cluster](https://github.com/yousefsalemW/Vprofile-Secured-Orchestrator)
  - [AWS Infrastructure with Terraform](https://github.com/yousefsalemW/Vprofile-terraform-on-aws-)
  - [Configuration Management with Ansible](https://github.com/yousefsalemW/containerization-with-Ansible)
  - [Hardened Container Image](https://github.com/yousefsalemW/vprofile-Dockerised)
  - Magistrala IoT Platform (volunteer contribution)
- **Alnaqib's Journey** — my public learning archive: [Alnaqib-s-Journey](https://github.com/yousefsalemW/Alnaqib-s-Journey)
- **Skills**, **Education and training**, and **Contact**
- **Download CV** — the CV PDF is embedded in the page, so the download works without a separate file

## Built with

A single static HTML file with inline CSS and JavaScript. No framework, no build step, no dependencies beyond Google Fonts (Source Serif 4 and IBM Plex Sans).

- Responsive layout down to mobile
- Keyboard-accessible project dialogs
- Respects reduced-motion settings

## Structure

```
Portfolio-/
├── index.html    # the whole site
└── README.md
```

## Run locally

Open `index.html` in a browser. No server is required.

## Deployment

Deployed on Vercel from the `main` branch. Every push to `main` triggers a new production deployment.
